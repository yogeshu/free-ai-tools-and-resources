# Getting started

## Choose the access pattern

- **Hosted API:** easiest to integrate, but prompts leave your device and are subject to the provider's policies, limits, and availability.
- **Local model:** runs on your hardware, but requires storage, memory, and an appropriate runner.

Start with the model and task you need rather than assuming the largest model is the best choice.

## Before using a hosted provider

Check the provider's official documentation for current pricing, quotas, authentication requirements, acceptable-use policy, data retention, and model-training policy. A record in this repository is a research aid, not a guarantee of continued availability.

## Before running locally

Check available RAM, VRAM, disk space, operating-system support, quantization options, and the runner's model format. Leave headroom for the operating system and application context.
