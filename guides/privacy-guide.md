# Privacy guide

“Free” does not mean private. Hosted inference sends prompts to a provider, where processing, logging, retention, and training practices depend on that provider and plan.

For sensitive material:

1. Remove secrets and personal information before sending a prompt.
2. Read the provider's current privacy and retention documentation.
3. Prefer a local model when the task and hardware support it.
4. Treat browser-based tools as hosted unless they explicitly document on-device inference.

This project records privacy caveats alongside access information so users can compare convenience and control instead of looking at price alone.
